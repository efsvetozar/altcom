# Говорю картинками

Бесплатное приложение для общения без речи: человек собирает фразу из картинок с подписями, приложение само приводит её к правильной русской грамматике и произносит вслух. Сделано для людей с афазией после инсульта (понимают речь и умеют читать, но не могут говорить), а также подходит при других нарушениях речи.

Работает без интернета, без регистрации и подписок. Все данные хранятся только на устройстве.

## Основные возможности
- **Картинки с подписями.** Плитки сгруппированы по вкладкам: «Начать», «Часто», «Фразы», «Сценарии», «Календарь», «Словарь», «Глаголы», «Вопросы», «Ответы», «Я / мой», «Люди», «Врач», «Вещи», «Город», «Время», «Даты», «Числа» и другие.
- **Грамматика.** Фраза склеивается правильно: падежи, род и число, числительные («два стола», «пять яблок»), предлоги, спряжение глаголов («Я» + «пойти» → «Я пойду», «Вчера она» + «пойти» → «Вчера она пошла»).
- **Подсказки.** Над вкладками показываются слова, которые чаще всего идут дальше. Они учатся на том, что человек говорит.
- **Озвучка.** Системный русский голос устройства, регулируются скорость, высота и громкость. Можно записать фразу своим голосом, и она будет звучать именно так.
- **Словарь на 3000 слов** с поиском и экранной клавиатурой (её можно скрыть). Найденные и использованные слова сами попадают на нужные вкладки.
- **Календарь и заметки**, готовые **сценарии** (у врача, магазин и аптека, такси, звонок родным, кафе) и сохранение **часто говорящихся фраз**.
- **Свои плитки:** своё фото (в том числе снимок с камеры), своя подпись, свой текст для озвучки. Ненужные плитки можно скрыть долгим нажатием.
- **«Поделиться».** Фраза отправляется в Макс, Telegram, SMS и другие приложения через системное меню.
- **Удобство.** Крупные кнопки для левой руки, три размера картинок, режим для телефона и планшета, анимация нажатия.
- **Резервная копия:** сохранение и загрузка всех плиток, записей и заметок одним файлом.

## Краткое руководство
**Собрать и сказать фразу**
1. Нажимай плитки по порядку: «Я хочу» → «Пить» → «Чай». Они появятся в строке сверху.
2. Нажми зелёную кнопку **«Сказать»**: приложение произнесёт «Я хочу пить чай».
3. Ошиблись: **⌫** стирает последнее слово, **✕** очищает всю фразу. Нажатие на слово в строке убирает именно его.

**Кнопки вверху**
- 🔊 **Сказать** — произнести фразу.
- 📤 **Поделиться** — отправить текст фразы в выбранное приложение и контакту.
- ⌫ **Стереть** и ✕ **Очистить**.

**Найти нужное слово**
- Вкладка **«Словарь»**: набери первые буквы, найди слово и нажми на него. Вкладка **«Глаголы»** работает так же, но для действий.
- Подсказки в строке «Дальше» предлагают следующее слово одним нажатием.

**Свои плитки и настройки**
- **⚙ нажми** — настройки: голос, скорость, размер картинок, левая рука, «💾 Сохранить копию» и загрузка копии.
- **⚙ удерживай секунду** — режим редактирования: правка, добавление и удаление плиток.
- **«➕ Добавить»** — последняя плитка на вкладке: своя картинка, подпись и произношение.
- **Долго нажать на плитку** — скрыть её; вернуть можно в режиме редактирования.
- **Записать свой голос:** в настройках → «🎙 Свой голос (записи фраз)».

**Если не слышно звука**
- Проверь громкость и беззвучный режим телефона.
- На iPhone русский голос нужно скачать: Настройки → Универсальный доступ → Устный контент → Голоса → Русский.
- Первый звук появляется после первого касания экрана.

# Установка и запуск

## Вариант 1. Установка как приложение (самый простой)
1. Выложи папку `docs` на бесплатный хостинг, например GitHub Pages (Settings → Pages → ветка main, папка /docs).
2. Открой адрес на телефоне/планшете:
   - Android, Chrome: меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
   - iPhone/iPad, Safari: «Поделиться» → «На экран Домой».
3. Первый запуск с интернетом, дальше работает без сети, открывается на весь экран, со своей иконкой.

## Вариант 2. Настоящий Android-файл (APK), бесплатно
1. Создай репозиторий на GitHub и загрузи в него всё содержимое этой папки.
2. Вкладка Actions → «Сборка Android APK» → Run workflow (или просто сделай push в main).
3. Через несколько минут внизу страницы запуска, в разделе Artifacts, появится `govoryu-kartinkami-apk`. Скачай, достань `app-debug.apk`, перекинь на планшет и установи (разреши «установку из неизвестных источников»).

Это отладочная сборка: для личного пользования годится, для публикации в Google Play нужна подпись и аккаунт разработчика (платный).

## Что проверить после установки APK
Сборку APK я не мог проверить у себя, поэтому на реальном устройстве посмотри:
- озвучка (голос Google из системных настроек);
- запись своего голоса (микрофон должен спросить разрешение);
- быстрое фото с камеры;
- открытие ссылки на чат в Max.
Если что-то не работает, напиши, что именно, поправим.

## Обновление
Замени `docs/index.html` на новую версию. Для PWA после публикации приложение обновится само при следующем открытии с интернетом. Для APK собери заново.

## iPhone и iPad
Приложение на iPhone ставится только как «значок на экране» (так устроен iOS), через Safari.
1. Выложи папку `docs` на GitHub Pages (Settings → Pages → ветка main, папка /docs). Получишь адрес вида `https://имя.github.io/altcom/`.
2. На iPhone открой адрес именно в Safari (не в Chrome).
3. Нажми «Поделиться» (квадрат со стрелкой) → «На экран “Домой”» → «Добавить».
4. Запускай с иконки: приложение откроется на весь экран и будет работать без интернета.
5. Голос: Настройки → Универсальный доступ → Устный контент → Голоса → Русский → скачай «Милена» или «Юрий» (улучшенного качества).
6. Первый звук появится после первого касания экрана: iOS не разрешает звук сам по себе.
7. Данные хранятся внутри иконки. Не удаляй иконку: данные удалятся вместе с ней. Раз в месяц делай резервную копию (⚙ → «💾 Сохранить копию»).
